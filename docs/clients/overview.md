# Clients

Phlix is available on a wide range of platforms — from living-room TVs to phones to the web browser on your laptop.

## Available Clients

| Platform | App | Notes |
|----------|-----|-------|
| [Windows](./windows) | Native app | Full media experience |
| [macOS](./web) | Web portal | No native macOS app — use the web portal in any browser (Safari, Chrome, Firefox, Edge). The Electron desktop source can be built for macOS, but no macOS artifacts ship and it is unsupported |
| [Linux](./web) | Web portal | No native Linux app — use the web portal in any browser (Firefox, Chrome, Edge). The Electron desktop source can be built for Linux, but no Linux artifacts ship and it is unsupported |
| [Mobile](./mobile) | iOS & Android | Stream on the go |
| [Web](./web) | Browser-based | No install needed |
| [Roku](./roku) | Channel app | For Roku devices |
| [Samsung Tizen](./tizen) | Smart TV app | For Samsung Smart TVs |
| [Console](./console) | Terminal TUI | Full-window terminal client |

## Skip Button

Phlix supports the [Skip Button protocol](./skip-button-integration-brief) for hands-free navigation during intros and recaps.
